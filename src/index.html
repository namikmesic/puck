    Welcome to Puck

    Configure a Docker environment, then chat with Claude Code or Codex.

    Settings

    Agents

    Named provider configurations — model, system instructions, thinking level, and advanced options. Pick an agent per chat session.

    Providers

    Sign in once per provider. The sign-in opens in your browser. Tokens are stored in the OS keychain (Electron safeStorage) and copied into every environment. If the keychain is unavailable, Puck refuses to store them rather than fall back to plaintext. Disconnect removes Puck's tokens and the copies in running environments.

    Environments

    Docker containers the harness runs in, with your workspace mounted at /workspace. Click a card to configure it.

    Support

    Puck keeps a diagnostic log on this Mac and sends nothing anywhere. When you report a problem, export the bundle below and attach it to the report.
